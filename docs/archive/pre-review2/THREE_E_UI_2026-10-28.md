# 3E Inspector UI refresh

Implemented locally on `fix/full-stack-audit-20261028`, after Feign commit `b4f3137`. Applies to both graph and diagram selections through their shared Inspector. No API, database, analyzer or dependency changes.

## Layout, from top to bottom

1. **Selection header:** prominent service/relationship name, secondary type, source-context badge and saved/preview counts. The close control remains visible while content scrolls.
2. **Pinned section navigation:** Explain, Evidence with count, and Evaluate. Existing Radix tabs provide keyboard arrows, selected states, focus handling and labelled panels.
3. **Explain:** one primary interpretation, compact provenance caveat, direct action to inspect evidence, communication contracts and an optional collapsed AI follow-up. Repeated summary paragraphs and the internal token-saving statistic no longer compete with the user's task.
4. **Evidence:** Caller/Receiver/configuration labels, full source locator, collapsed interpretation and code, copy feedback, progressive evidence pagination. Loading, retryable error and metadata-preview states remain distinct. Group selections retain member drilldown and return navigation. Technical metadata, related edges and sequence provenance are grouped under selection details.
5. **Evaluate:** assessment and readable assumptions/unknowns, plus an action returning to supporting evidence. Missing findings never imply correctness or safety.
6. **Pinned footer:** model revision and interpretation provenance.

The panel uses the existing white/slate surfaces and blue accent, emerald source context and amber model-only/unknown states, with theme tokens for dark mode. Body text is 14px with generous line height; source and provenance metadata are smaller. Evidence code retains horizontal scrolling without widening the page. The desktop panel is 380–440px and 480px on wide screens. Mobile uses a bounded bottom panel with pinned header/tabs/footer and one main content scroll area.
