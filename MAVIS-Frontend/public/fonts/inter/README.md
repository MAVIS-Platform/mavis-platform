# Inter for MAVIS

Inter Variable, version 4.1, is served locally from `InterVariable.woff2`.

- Source: https://github.com/rsms/inter/blob/v4.1/docs/font-files/InterVariable.woff2
- License: SIL Open Font License 1.1; retained in `LICENSE.txt`.
- Upright variable font; CSS uses weights 400, 500 and 600, with the complete 100–900 range declared for compatibility.
- The full upstream font is retained rather than a Latin-only subset, supporting the Vietnamese typography specimen.
- Loading uses `font-display: swap` with Segoe UI/system sans-serif fallbacks. No third-party font service or npm package is required.
